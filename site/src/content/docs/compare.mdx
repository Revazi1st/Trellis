Trellis beside four other .NET solution templates: [jasontaylordev/CleanArchitecture](https://github.com/jasontaylordev/CleanArchitecture), [ardalis/CleanArchitecture](https://github.com/ardalis/CleanArchitecture), [amantinband/clean-architecture](https://github.com/amantinband/clean-architecture) and [fullstackhero/dotnet-starter-kit](https://github.com/fullstackhero/dotnet-starter-kit). Every cell about another project was read on 2026-11-15 from that project's own repository: its settings and latest release on GitHub, and files such as its `template.json`, its package list and its workflows. A dash means the fact was not recorded, not that it is absent; "none found" means the repository was searched and holds none. The Trellis column describes this repository, and its version and its option count are read from it when this site is built.
