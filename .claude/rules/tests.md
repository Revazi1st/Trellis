# Testing rules

- **xUnit v3** + **Shouldly** (`value.ShouldBe(...)`). Mocks: **NSubstitute**. Never FluentAssertions or Moq.
- Test names: `Method_Scenario_Outcome`.
- **Domain.UnitTests**: pure, no mocks. **Application.UnitTests**: handlers/decorators with faked ports (`Substitute.For<...>`), `FakeTimeProvider` for time.
- **IntegrationTests**: real PostgreSQL via `IntegrationTestBase` (Testcontainers + Respawn) — exercise the real Application pipeline against a real DB. **Do not mock EF or the DbContext.** Includes the migration-drift guard (`HasPendingModelChanges` — a model change without a migration fails here) and the domain-event serialization fitness test.
- **ArchitectureTests**: `LayerDependencyTests` for boundaries — add a rule when you introduce one. `ConventionTests` enforce the rules files — a new convention gets a test, not just prose:
  - by reflection: sealed non-public handlers, `internal sealed` endpoints, value-object `Create → Result<T>` shape, aggregate encapsulation (no public constructors or setters), sealed-record events, and a unique lowercase-dotted `[DomainEventHandlerName]` on every domain-event handler (the outbox's completion key);
  - by source scan (`RepositorySource`): every catch filter that lets `OperationCanceledException` through keys on the host or request token (`cancellationToken` / `stoppingToken`, never a linked token) across `src/` and `tools/`, and `IgnoreQueryFilters()` is never called bare across `src/`, `tools/` and `tests/` (a deliberate exception goes on the allowlist with its reason).
  `NamingConventionTests` cover namespace-mirrors-folder, the `Async` suffix (SharedKernel is exempt: `Handle`/`Bind`/`Map` are named after their patterns) and role suffixes. `OptionsConventionTests` require a validation attribute on every `*Options` type and boot the real API host to prove each is validated at start (and that an out-of-range value stops it naming the key). `TelemetryNamingTests` keep meters, sources, instruments and attributes on the `Trellis.*` / `trellis.*` prefixes with units.
- **ApiTests/InProcess**: `ApiFactory` (`WebApplicationFactory` + Testcontainers PostgreSQL) runs the **real HTTP pipeline** — JWT 401/403, permission policies, idempotency (replay, fingerprint 422, in-flight and duplicate 409, nothing reserved by a failed command), the auth rate limit, the RFC 9457 shape (`ProblemDetailsContractTests`: one test per status, every body deserialised into `ProblemResponse`; a new status or `code` gets a row there) — inside the SDK container on every `test` run. Aspire E2E stays opt-in (`RUN_ASPIRE_E2E=1`); contract-serialization guards are always on. The fixture contract (ADR-0021):
  - Every `CreateClient()` calls from its own simulated address (`ApiFactory.ClientAddressHeader`, applied by an outermost startup filter), so each client is its own anonymous rate-limit partition and no test spends another's `auth` budget. Model many users behind one host with `CreateClientFrom(address)`.
  - Fixtures state `Registration:Mode=Open`, and a host setting cannot be unset; a test about shipped defaults boots a plain `WebApplicationFactory<Program>` instead (`AuthFlowTests.Register_WithTheShippedProductionConfiguration_IsClosed`).
  - Kestrel-only behaviour (request-size limits) runs on a real listener: `RequestLimitTests.KestrelApiFactory` (in `EndpointMetadataTests.cs`) calls `UseKestrel(0)`, because TestServer does not enforce Kestrel limits.
  - `AuthFlowTests.Factory` swaps in observers instead of mocks: an adjustable clock (token expiry), a counting password hasher (timing oracle), a capturing `ILoggerProvider` (security events).
  - Move time, never sleep: `ApiFactory.Time` is a settable clock registered as the host's `TimeProvider` — `Advance(...)` it and `Reset()` it in a `finally`, because the fixture is shared (`TenantIsolationTests` makes an invoice overdue this way; a derived factory's own clock still wins).
- **ApiTests/Ui** (absent with `--include-ui false`): UI.Common's clients and token provider over a scripted handler and a manual clock (`UiHarness`); every file sits behind the `IncludeUI` conditional and the csproj references UI.Common under the same guard.
- **OpenAPI** (ADR-0025): `OpenApiSnapshotTests` (in-process) proves `docs/api/openapi.v1.json` is the document the API serves — any wire change fails every `dotnet test` run until you regenerate (`UPDATE_OPENAPI_SNAPSHOT=1 dotnet test tests/Trellis.ApiTests`, forwarded by `scripts/dotnet.sh`, or `scripts/export-openapi.sh` against a running API; the committed bytes are the server's serialisation plus a final newline) and commit the diff. `OpenApiDocumentTests` gate the document's content: summary **and** description on every operation, probes out, a unique `operationId` per operation (the endpoint class), no `{version}` or `servers`, every 4xx/5xx `$ref`-ing `ProblemResponse` (which requires only `type`/`title`/`status`/`code`), 400/404 by shape, the Result statuses of the anonymous auth operations (declared with a bare `.Produces(status)`), `Location` on 201, `If-None-Match`/`ETag`/304 on a conditional GET, camelCase bounded paging, string-enum status / decimal money / int64 version. `InvoiceContractTests` proves those promises on the wire (304 for weak, strong, list and `*` tags; paging bounds answer 400 naming the field; `Location` resolves). A Contracts enum that mirrors a domain enum gets a `ContractMirrorTests` fact in ArchitectureTests.
- Use `TestContext.Current.CancellationToken` for cancellable calls.
